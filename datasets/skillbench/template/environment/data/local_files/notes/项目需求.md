# 医疗预约 H5 页面需求文档

## 项目背景
快速上线医疗预约系统，支持患者在线预约挂号，并集成飞书审批流程。

## 核心功能
1. 科室选择与医生展示
2. 号源查询与预约
3. 患者信息填写
4. 飞书审批流集成
5. 预约确认通知

## 技术栈
- 前端：React + TypeScript
- 样式：TailwindCSS（响应式）
- 部署：飞书小程序/H5 嵌入

## 飞书集成要求
- 使用飞书多维表格管理号源数据
- 预约申请触发飞书审批流
- 审批结果通过飞书机器人通知

## 优先级
P0: 基础预约流程 + 飞书审批
P1: 号源可视化 + 取消预约
P2: 评价系统 + 数据统计

## 时间节点
- 设计稿确认：2 天内
- 前端开发：5 天
- 联调测试：3 天
- 上线：第 10 天
